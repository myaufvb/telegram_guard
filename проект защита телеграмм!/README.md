# 🛡️ Telegram Guard — Веб-платформа защиты аккаунта Telegram

Полный комплекс защиты аккаунта Telegram с интеграцией авторизационного бота `@Defense_telegram_lerman_bot`, личным кабинетом управления безопасностью, международным вводом номеров и модулем ограничения количества активных устройств.

---

## 🌟 Ключевые возможности

1. **Международная авторизация (E.164):**
   - Выбор кодов любых стран мира (`🇺🇿 +998`, `🇷🇺/🇰🇿 +7`, `🇺🇦 +380`, `🇧🇾 +375`, `🇦🇿 +994`, `🇬🇪 +995`, `🇹🇷 +90`, `🇺🇸 +1` и др.).
   - Автоматическая нормализация номеров к международному формату.

2. **Telegram Бот авторизации (`@Defense_telegram_lerman_bot`):**
   - Поделившись контактом в боте, система сверяет номер телефона Telegram с введенным на сайте.
   - Высылка 6-значных безопасных кодов подтверждения.

3. **Интерактивный личный кабинет (Дашборд) с 3 вкладками:**
   - 🛡️ **«Защита Telegram»:** Настройка числового лимита устройств в строке (например: 1, 2, 3...), список сессий в реальном времени, сервис авто-выбивания 3-го лишнего устройства.
   - 🔐 **«Защита аккаунта на сайте»:** Пароли, сессии веб-приложения.
   - ⚙️ **«Настройки»:** API ключи и уведомления.

4. **Визуализация ошибок ввода (Красная подсветка):**
   - При вводе несуществующего аккаунта или неверного пароля соответствующее поле мгновенно подсвечивается **ярким красным цветом** (`border: 2px solid #ff4d4d`) с выводом понятного описания ошибки.

5. **Готовность к развертыванию на Railway:**
   - Наличие готовых `Dockerfile` и `Procfile`.
   - Единая точка запуска сервера и бота через `python main.py`.

---

## 🚀 Локальный запуск на ПК

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите единый скрипт:**
   ```bash
   python main.py
   ```

3. Откройте в браузере: `http://localhost:8000`
